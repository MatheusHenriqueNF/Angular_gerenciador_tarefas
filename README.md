# Gerenciador de Tarefas

Projeto de portfólio **Angular + TypeScript** com componentes standalone.

## Funcionalidades
- Cadastro, conclusão e exclusão de tarefas.
- Filtros por status, sinais (`signal`) e valores calculados (`computed`).
- Persistência no localStorage.
- Layout responsivo.

## Como executar

Requisitos: Node.js compatível com Angular 20 e npm.

```bash
npm install
npm start
```

Acesse http://localhost:4200. Para criar a versão de produção: `npm run build`.

## Tecnologias
Angular 20, TypeScript, HTML, CSS.

## Observações
Exemplo didático, sem backend. Dados salvos apenas neste navegador quando indicado.
